## How it works (repo layout)

- `places.yaml` — the catalog: window, lidar projects, `story` paragraphs and
  `sources`. Every sentence in a story has been checked against its sources.
- `motherlode/` — `fetch.py` (EPT ground returns, multi-survey mosaic with
  median seam shift), `relief.py`, `web.py` (copied from Project Kiva), `cli.py`.
- `scripts/fetch_mines.py` — USMIN + MRDS from the USGS WFS at mrdata.usgs.gov
  (GML parsed by hand; GeoJSON output isn't offered), clipped to
  `data/tuolumne.geojson`.
- `scripts/web_data.py` — writes `docs/data/mines.geojson` and
  `docs/data/places.json`. **Run it after any `places.yaml` edit** and commit.
- `scripts/blog_figures.py OUT_DIR` — labelled figures (legend, 500 m scale
  bar, north arrow) for the blog, `X.jpg` (1200 px) and `X-full.jpg` (2400 px).
  Writes into `bdgroves.github.io/blog/img/mother-lode/`.
- Workflows (all manual, `workflow_dispatch` only):
  - `build.yml` — input `places` (comma ids) → `docs/sites/<id>/` + `logs/`.
  - `mines.yml` — refetch mine data.
  - `probe.yml` — ask a data source what it has; results in `data/_probe/`.

Dispatch from the sandbox:
`gh api -X POST repos/bdgroves/mother-lode/actions/workflows/build.yml/dispatches -f ref=main -f 'inputs[places]=columbia'`

## Gotchas learned the hard way

- The sandbox can't reach USGS, ScienceBase, Macrostrat or AWS lidar. Fetch on
  GitHub Actions and commit results. `raw.githubusercontent.com` works for reads.
- The GitHub Pages API (`/repos/.../pages`) is blocked through the proxy: Brooks
  turns Pages on himself (Settings → Pages → `main` + `/docs`).
- GitHub Actions has had long queues today (30–40 min). If a run sits
  `queued`, wait or cancel and re-dispatch once; don't loop.
- A push from the workflow can collide with a push from here: workflows use
  `git pull --rebase` before pushing.
- `little-free-pantry` is **archived** on GitHub (read-only). Brooks unarchives
  it to push, then may re-archive. The Claude GitHub App can't push to it.
- `my.usgs.gov` ArcGIS services returned 503; use `mrdata.usgs.gov` WFS.
- MRDS has duplicate and misspelled names (Eagle-Shawmut ×3, "Morhman").
  `blog_figures.py` normalises names before labelling.
- Lidar shows water as a hole (no returns): pit lakes and reservoirs are blank.
